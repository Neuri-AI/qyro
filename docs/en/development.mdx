# Development and contribution

```bash
git clone https://github.com/Neuri-AI/qyro.git
cd qyro
poetry install --with dev
poetry run pytest -q
poetry run pytest --cov=qyro --cov-report=term-missing
```

The suite covers Component lifecycle/props/styles, ApplicationContext state/title/icon/resources, flattened frozen paths, protected settings/resources, embedded and legacy secrets, tampering, AES-GCM/HKDF roundtrips, and avoidance of secret logging.

Protected-bundle tests compile a temporary Cython extension. Cython is not currently declared in the dev group, so that test environment must supply Cython and a C compiler.

## Architecture conventions

- pure entities and rules in `domain/`;
- interfaces in `application/ports/`;
- orchestration in `application/use_cases/`;
- external technologies in `adapters/`;
- user-facing ergonomics in `client/`;
- wiring in `container.py`.

For a public change, define errors/types, add GUI-independent tests where possible, re-export only intentional stable APIs, update README and both doc languages, and validate source/frozen plus headless behavior.

## Release pipeline

Publishing a GitHub Release triggers a Python 3.10 job that installs Poetry 2.0.1, installs all extras, builds distributions, uploads them as an artifact, and publishes through PyPI Trusted Publishing. Dependabot checks Poetry dependencies weekly.

<Warning>The `all` extra combines incompatible Python ranges for legacy and modern Qt bindings. Revalidate the release job whenever dependency constraints change.</Warning>

## Maintenance notes

- `pyproject.toml` declares version `1.0.0a2`; `qyro.__version__` says `0.1.0`.
- The current NOTICE is headed “Qyro CLI” and discusses ecosystem tools; review it before a runtime release.
- The runtime is MIT, but redistributed GUI bindings have their own licenses.

## Review checklist

- Is first global initialization deterministic?
- Does the package still import without optional GUI toolkits?
- Are Qt objects created from the matching binding?
- Do paths work in both source and frozen modes?
- Are secrets absent from logs and extracted trees?
- Are authentication failures strict and UI operations best-effort?
- Are high-level return types (`str` vs `Path`) consistent?
- Were Spanish and English docs updated?
