PySide6 is the binding that provides the Qt widgets. The [official Qt template](https://github.com/Neuri-AI/qyro-boilerplate-qt) combines the window, `Component`, and `ApplicationContext` through multiple inheritance; Qyro prepares `QApplication`, configuration, and resources before displaying it.

## Setup

The engine can run using Python `>=3.10,<3.14`. With your project's environment active:

```bash
pip install --pre "qyro-engine[pyside6]"
```

Use a project created with `qyro init` and `--binding PySide6`, as in [Your first application](/en/quickstart). Place this code in the script specified by `entry_point` and run it from the project with `qyro start`. The example shows the minimal window; keep the settings generated by the CLI.

```python
import sys
from PySide6.QtWidgets import QMainWindow, QLabel
from qyro import ApplicationContext
from qyro.ui.component import Component


class MiApp(QMainWindow, Component, ApplicationContext):

    def component_will_mount(self):
        self.setMinimumSize(640, 480)

    def render(self):
        label = QLabel(
            f"Hello, World!\n\n\n"
            f"App Title: {self.window_title}\n\n"
            f"Active Icon: {self.app_icon}\n\n"
            f"Platform: {self.platform.value} (Frozen: {self.is_frozen})\n",
            parent=self,
        )
        label.move(50, 50)
        label.resize(label.sizeHint())


if __name__ == "__main__":
    window = MiApp()
    window.show()
    sys.exit(window.run())
```

`Component` calls `component_will_mount()` and then `render()`. `ApplicationContext` creates or reuses `QApplication`, applies the configured title and icon, and provides `run()`. Finally, `sys.exit()` returns Qt's exit code to the system.

## Configuration, components, and resources

In a CLI-managed project, use `"binding": "PySide6"` and `"entry_point": "main.py"` in `settings/base.json`. The binding must match the package imported by the entry point.

For a reusable widget, you can inherit from `QWidget, Component` or apply `@Component`. The hooks run after the constructor, and QSS is applied with `setStyleSheet`; read [Components](/en/components) before passing props. Reserve `ApplicationContext` for the main window.

In [Complete applications](/en/examples), you will find `pyside6_app.py`, which adds settings, platform-specific text, a `Panel` with props, a stylesheet as a resource, and a counter without a state-management dependency. The same resource access is used in frozen mode.

## Limitations and validation

Install and use a single Qt binding per process. Icon paths follow [Resources](/en/resources); their format and rendering depend on the system. It was executed locally on Windows/Python 3.13.

The extra's constraints describe installation, not a guarantee of wheel availability or support for every platform. See [Compatibility](/en/compatibility) and [Build](/en/tooling).
