# Resources

Resources are queried with relative segments and returned as absolute paths:

```python
logo = context.get_resource("images", "logo.png")
font = get_resource("fonts/Inter.ttf")
```

`ResourceQuery.from_segments()` splits every argument with `Path.parts`, so both forms are normalized.

## Root precedence

An existing `custom_resources_dir` becomes the only root. Otherwise protected-bundle resources come first, followed by frozen or source roots.

Platform directories precede generic ones:

```text
resources/windows/ or resources/win32/
resources/mac/ or resources/darwin/
resources/linux/
resources/base/
resources/
```

Equivalent `src/main/resources/` paths are supported. A platform asset therefore overrides a `base` asset with the same relative path.

## Source and frozen roots

Source lookup starts at `get_root_dir()`. Frozen lookup starts at:

- `sys._MEIPASS` for PyInstaller;
- macOS `Contents/Resources` when detected;
- otherwise the executable/root directory.

Internal `ResourceResult` values include absolute path, existence, frozen/bundled state, and target OS on success.

## Flattened bundles

When a query starts with `base`, `windows`, `win32`, `mac`, `darwin`, or `linux`, Qyro also tries the path without that prefix. This supports bundles that flatten platform folders.

```python
get_resource("base", "images", "avatar.png")
get_resource("windows", "icons", "app.ico")
```

## Required vs optional

```python
schema = context.get_resource("schemas", "main.json")
candidate = context.get_resource("themes", "seasonal.qss", required=False)
```

Required misses raise `ResourceNotFoundError`. Optional misses return an absolute candidate string, so call `Path(candidate).exists()` before using it.

## Listing

```python
paths = context.container.resource_adapter.list_resources("images")
```

Listing combines immediate children from every existing root. It is not recursive, includes files and directories, and deduplicates through a set, so output order is not guaranteed.

For a resource-only override, construct `EngineContainer(custom_resources_dir=Path(...))`; `ApplicationContext` exposes `custom_root` but not the specialized resource/settings directories.
