---
title: "PySide6 demos"
description: "Small runnable Qyro Engine applications for PySide6."
---

The runnable project is in
[`examples/pyside6-cli-runtime`](https://github.com/Neuri-AI/qyro-engine/tree/main/examples/pyside6-cli-runtime).
The project was generated with `qyro init`; run it from that directory:

```bash
qyro start
```

The tabs cover the application context, settings, platform-specific resources,
component lifecycle and props, stylesheet loading, the advanced
`EngineContainer` API, and optional Pydux reactive state. Run `pytest` in the
same folder for the headless settings/resource contract test. The Spanish page
contains the detailed walkthrough and frozen/protected-resource notes.
