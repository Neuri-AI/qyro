# Instalación

En esta página prepararás un entorno aislado e instalarás las herramientas para crear una aplicación con Qyro CLI y PySide6. Un **entorno** separa el intérprete y las dependencias de este proyecto de las de otros proyectos.

Utiliza **Python 3.13** para seguir este recorrido. El Engine admite un rango más amplio, pero cada binding tiene sus propios requisitos. Puedes preparar el entorno con `venv` o Conda; elige una de las dos opciones siguientes.

## 1. Crear y activar el entorno

### Con venv

Necesitas Python 3.13 instalado. Desde tu carpeta de trabajo, crea el entorno:

```bash
python -m venv .venv
```

`venv` crea `.venv/` con un intérprete y espacio propio para instalar paquetes. Actívalo según tu terminal.

En **Windows PowerShell**:

```powershell
.\.venv\Scripts\Activate.ps1
```

En **Windows CMD**:

```bat
.venv\Scripts\activate.bat
```

En **macOS o Linux**:

```bash
source .venv/bin/activate
```

La activación hace que `python`, `pip` y los comandos instalados correspondan al entorno. Para salir después, utiliza `deactivate`.

### Con Conda

Si utilizas Conda, crea y activa un entorno:

```bash
conda create --name qyro-app python=3.13 pip -y
conda activate qyro-app
```

La primera orden crea el entorno `qyro-app` con Python y pip; `-y` acepta la confirmación. La segunda lo activa. Puedes elegir otro nombre. Para salir después, utiliza `conda deactivate`.

### Confirmar el intérprete

Con el entorno activo:

```bash
python --version
python -m pip install --upgrade pip
```

Comprueba que la versión sea la que elegiste. La segunda orden actualiza pip dentro de ese entorno. Usaremos `python -m pip` para que las instalaciones correspondan al intérprete activo.

## 2. Instalar Qyro para PySide6

```bash
python -m pip install --pre "qyro-cli[desktop]" "qyro-engine[pyside6]"
```

Esta orden instala desde el índice de paquetes:

- **`qyro-cli[desktop]`:** el comando `qyro` y herramientas de escritorio, incluidas PyInstaller, Pillow y Cython.
- **`qyro-engine[pyside6]`:** el motor importable como `qyro` y el binding PySide6 con el que escribirás la interfaz.
- **`--pre`:** permite seleccionar las versiones preliminares de los paquetes, actualmente en alpha.

Los corchetes indican un **extra**: un grupo de dependencias opcionales. `desktop` añade herramientas de build al CLI; `pyside6` añade un toolkit al Engine. Son extras de paquetes distintos.

El desarrollo normal no necesita compilar el Engine. Para ejecutar `qyro build` sí necesitas un compilador C compatible con el Python del entorno, porque el CLI compila su módulo runtime mediante Cython. Los requisitos de build se explican en [Build y distribución](/es/tooling).

## 3. Comprobar la instalación

```bash
qyro --help
qyro version
python -c "from qyro import ApplicationContext; from PySide6.QtWidgets import QApplication; print('Qyro y PySide6 disponibles')"
```

La ayuda comprueba el comando; `version` muestra los paquetes detectados; la última orden comprueba los imports para la primera aplicación. Si la terminal no encuentra `qyro`, confirma que el entorno esté activo y prueba `python -m qyro_cli --help`.

## Otros bindings

Puedes mantener el CLI e instalar el extra del Engine que corresponda a tu aplicación. Por ejemplo:

```bash
python -m pip install --pre "qyro-engine[pyqt6]"
```

| Extra del Engine | Dependencia | Rango adicional del manifest auditado |
| --- | --- | --- |
| `pyside6` | PySide6 | Python `>=3.11,<3.15` |
| `pyqt6` | PyQt6 | Python `>=3.11,<3.15` |
| `pyqt5` | PyQt5 | Python `>=3.11,<3.14` |
| `pyside2` | PySide2 | Python 3.10 al combinarse con el rango del Engine |
| `kivy` | Kivy | Sin marcador adicional de Python |
| `sentry` | sentry-sdk | Sin marcador adicional de Python |
| `all` | Todos los grupos opcionales anteriores | Se aplican los marcadores de cada dependencia |

Tkinter depende de Tcl/Tk disponible en tu Python y no requiere un extra del Engine.

### Instalar todos los extras

```bash
python -m pip install --pre "qyro-engine[all]"
```

`all` solicita **todos los extras del Engine**: PySide6, PyQt6, PyQt5, PySide2, Kivy y Sentry. Pip descarga e instala los que correspondan a la versión de Python del entorno según sus marcadores. Por ejemplo, en Python 3.13 el marcador de PySide2 lo excluye. No incluye el CLI ni librerías independientes de estado. Para desarrollar la primera aplicación basta con `pyside6`.
