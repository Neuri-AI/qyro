---
title: "VeltoContext"
description: "Ejecuta una interfaz PSX desde los settings de Qyro."
---

`VeltoContext` es el punto de entrada UI de Qyro. Carga settings, recursos y
telemetría, y después crea el renderer seleccionado de Velto. Los componentes
pertenecen a Velto: usa `psx()` y `@component`, no clases de widgets de Qyro.

```python
import sys
from qyro import VeltoContext
from psx import component, psx

@component
def Notice():
    return psx("<Text>Renderizado por Velto.</Text>")

class MyApp(VeltoContext):
    def render(self):
        return psx('''
            <Flex direction="column" align_items="center" width="100%">
                <Text>Hello, Velto!</Text>
                <Notice />
            </Flex>
        ''')

if __name__ == "__main__":
    sys.exit(MyApp().run())
```

`mount()` devuelve el handle nativo de Velto, `run()` monta una sola vez y
entra al loop del renderer, y `unmount()` desmonta el árbol PSX. El contexto
también expone `metadata`, `app_settings`, `get_resource()`, `platform`,
`is_frozen` y `execution_mode`.

`VeltoContext` compila su método `render()` dentro de un límite de componente
PSX. Por ello la vista raíz puede usar `use_state`, condicionales estilo JSX y
f-strings de Python igual que una función normal con `@component`. No decora
el método con `@component`.

## Settings

`framework` selecciona `PySide6`, `PySide2`, `PyQt6`, `PyQt5`, `Kivy` o
`Tkinter`; `binding` se conserva como fallback legacy. Si ambos existen,
gana `framework`. `window.width` y `window.height` definen el tamaño nativo
inicial y el viewport SFLE de Velto.

```json
{
  "app_name": "Ejemplo",
  "framework": "PySide6",
  "window": {"width": 800, "height": 600},
  "icon": "icons/app.png"
}
```

Ambas dimensiones deben ser enteros positivos. Si `window` falta o no es
válido, Qyro usa `800×600`. Qyro aplica `app_name` como título y resuelve
`icon` o `app_icon` desde resources antes de presentar la raíz de Velto.

## Migración incompatible

Se eliminaron `ApplicationContext`, `Component`, `qyro.ui` y los adaptadores
de frameworks de Qyro. Sustituye la herencia múltiple de ventanas nativas y
los hooks por una subclase de `VeltoContext` cuyo `render()` devuelve un VNode
PSX.
