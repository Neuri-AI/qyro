# Qyro con PyQt6

PyQt6 es el binding que proporciona los widgets Qt. Qyro prepara `QApplication`, configuración y recursos. Esta guía usa composición explícita para asegurar que la aplicación nativa existe antes del primer widget.

## Preparar

El extra del Engine declara Python `>=3.11,<3.15`. Con el entorno de tu proyecto activo:

```bash
python -m pip install --pre "qyro-engine[pyqt6]"
```

Utiliza un proyecto creado con `qyro init` y `--binding PyQt6`, como en [Tu primera aplicación](/es/quickstart). Coloca este código en el script indicado por `entry_point` y ejecútalo desde el proyecto con `qyro start`. El ejemplo muestra la ventana mínima; conserva los settings generados por el CLI.

```python
from pathlib import Path
from PyQt6.QtWidgets import QLabel, QMainWindow
from qyro import ApplicationContext


def main():
    context = ApplicationContext(
        framework="pyqt6", custom_root=Path.cwd().resolve(), enable_sentry=False
    )
    window = QMainWindow()
    window.resize(520, 240)
    window.setCentralWidget(QLabel("Hola desde Qyro", window))
    context.set_window_title(context.get_default_window_title(), window=window)
    window.show()
    return context.run()


if __name__ == "__main__":
    raise SystemExit(main())
```

El contexto crea o reutiliza `QApplication.instance()`. Mostrar la ventana no basta para procesar eventos: `context.run()` entra en `exec()` si existe y, de lo contrario, `exec_()`. Devuelve su código de salida. El adaptador `exit(code)` llama a la salida nativa.

## Configuración, componentes y recursos

En un proyecto gestionado por CLI, usa `"binding": "PyQt6"` y `"entry_point": "main.py"` en `settings/base.json`. La selección explícita del código prevalece sobre settings; no configures un binding diferente del que importan tus widgets.

Para un widget reutilizable puedes heredar de `QWidget, Component` o aplicar `@Component`. Los hooks se ejecutan tras el constructor, y QSS se aplica con `setStyleSheet`; lee [Componentes](/es/components) antes de pasar props. `ApplicationContext` también admite mixin, pero no es necesario para este ejemplo.

En [Aplicaciones completas](/es/examples) encontrarás `pyqt6_app.py`, que añade settings, texto por plataforma, un `Panel` con props, stylesheet como recurso y un contador sin dependencia de manejo de estado. El mismo acceso a recursos se utiliza en frozen.

## Límites y validación

El ejemplo completo utiliza un constructor posicional y asigna props después de inicializar `QWidget`, para evitar la ruta de acceso prematuro observada en PyQt5. No se presenta como una prueba gráfica de PyQt6; consulta [Componentes](/es/components).

Instala y usa un único binding Qt por proceso. Las rutas de iconos siguen [Resources](/es/resources); el formato y su representación dependen del sistema. No estaba instalado en el entorno de auditoría; se verificaron sintaxis y correspondencia con el adaptador, sin ejecución gráfica local.

Las restricciones del extra describen instalación, no una garantía de disponibilidad de wheels ni de todas las plataformas. Consulta [Compatibilidad](/es/compatibility) y [Build](/es/tooling).
