# Qyro con Tkinter

Tkinter proporciona la ventana y widgets; Qyro aporta contexto, settings y rutas. No hay extra `tkinter`: Python debe incluir Tcl/Tk. Sigue el procedimiento de [Tu primera aplicación](/es/quickstart), seleccionando `--binding Tkinter` al crear el proyecto con el CLI. Esta guía explica cómo cambia la integración respecto al recorrido PySide6.

## Quién crea la ventana

`TkinterAdapter.create_application()` recupera `_default_root` si ya existe, pero no crea un root. Crea explícitamente `tk.Tk()`, configura tus widgets y llama a `context.run()`. El adaptador recupera ese root y entra en `mainloop`; si no hay root, intenta crear uno. Un error de creación puede dejarlo sin aplicación y terminar con `0`, por lo que ese código de salida no prueba que apareció una ventana.

Por composición, `context.app` puede conservar el valor del arranque, incluso `None`, mientras el adaptador recupera el root posteriormente. Guarda tu referencia `root`.

## Eventos, estilos y cierre

Usa `pack`, `grid` o `place`, callbacks nativos y variables Tk para estado local. Un contador simple no necesita Pydux. QSS no se traduce a Tkinter: `Component.set_styles()` no hace nada cuando falta `setStyleSheet`. El wrapper `resizeEvent` es Qt; para tamaños usa `<Configure>` o los layouts de Tk.

`root.destroy()` destruye la ventana. También puedes llamar `context.container.framework_adapter.exit()` cuando el adaptador conoce el root. Para liberar recursos propios registra un callback en `WM_DELETE_WINDOW` y ejecuta tu limpieza antes de destruir.

Los iconos `.ico` intentan `iconbitmap`; otros archivos intentan `PhotoImage` e `iconphoto`, conservando una referencia para evitar recolección. No todos los formatos son admitidos.

## Aplicación completa

El archivo `docs/es/example-apps/tkinter_app.py` carga un texto con `get_resource`, aplica dimensiones de settings y muestra metadatos, plataforma y modo. Sigue [Aplicaciones completas](/es/examples) para ejecutarlo. Se validó creando widgets y procesando eventos, con cierre automático del test.

La [integración Pydux](/es/pydux) muestra una alternativa solo cuando necesitas un store compartido; su bridge utiliza `after_idle` y requiere limpieza explícita.
