# Mapa del código

Esta página sirve como índice de mantenimiento del repositorio. Los archivos `__init__.py` reexportan símbolos de su paquete salvo que se indique lo contrario.

Lee [Arquitectura](/es/architecture) antes del inventario. Un símbolo importable desde adapters no es automáticamente API estable; la superficie principal está en [Referencia](/es/api-reference).

## Raíz y automatización

| Archivo | Responsabilidad |
| --- | --- |
| `pyproject.toml` | Metadata Poetry, Python `>=3.10,<3.16`, dependencia criptográfica, extras GUI/Sentry y grupo dev. |
| `poetry.lock` | Resolución reproducible de dependencias. |
| `README.md` | Presentación, compatibilidad, instalación, ejemplos y API resumida. |
| `LICENSE` | Licencia MIT del runtime. |
| `NOTICE` | Notices del ecosistema y toolkits; actualmente está redactado bajo el encabezado Qyro CLI. |
| `.gitignore` | Excluye IDE, caches, bytecode, builds, dist, `src/` y `.env`. |
| `.github/workflows/python-publish.yml` | Build y publicación OIDC a PyPI al publicar un GitHub Release. |
| `.github/dependabot.yml` | Actualización semanal del ecosistema Poetry. |
| `.github/FUNDING.yml` | Configura Buy Me a Coffee para `neuri`; otros proveedores están vacíos. |
| `docs/docs.json` | Tema, colores y navegación bilingüe de Mintlify. |

## API y composición

| Archivo | Responsabilidad |
| --- | --- |
| `qyro/__init__.py` | API top-level, versión y contenedor procedural singleton. |
| `qyro/container.py` | Composition root: crea adaptadores y casos de uso. |
| `qyro/client/context.py` | `ApplicationContext`, singleton global, MRO, metadata, icono, título, recursos y loop. |
| `qyro/client/component.py` | `Component` como mixin/decorador, props, lifecycle, estilos, resize y utilidades. |
| `qyro/client/__init__.py` | Reexporta `ApplicationContext`. |
| `qyro/ui/component.py` | Ruta de compatibilidad que reexporta `Component`. |
| `qyro/ui/__init__.py` | Reexporta `Component` desde `qyro.ui`. |

## Pruebas

| Archivo | Cobertura |
| --- | --- |
| `tests/test_client_component.py` | Decorador, orden de hooks, props, estilos, find/calc/destroy. |
| `tests/test_client_context.py` | Boot info, loop, metadata, título, icono y recursos con fakes. |
| `tests/test_filesystem_resource_adapter.py` | Paths base/plataforma aplanados y estructurados en frozen. |
| `tests/test_protected_bundle_runtime.py` | `.pak`, settings, recursos, secretos, tampering y legacy. |
| `tests/test_secrets_crypto.py` | Roundtrip, headers, autenticación, aleatoriedad, plataformas y no logging. |

Los directorios `build/`, caches y bytecode son artefactos generados, no parte de la API fuente.

## Tooling y estado opcional

Estas rutas pertenecen a otros repositorios, no al Engine:

| Ruta desde cada repositorio | Responsabilidad |
| --- | --- |
| CLI: `qyro_cli/cmdline/commands` | Registro, comandos, argumentos y aliases |
| CLI: `qyro_cli/application/use_cases` | Init, start, freeze, bundle, sign, clean y versiones |
| CLI: `qyro_cli/adapters/templates` | GitHub, caché y fallback; el checkout no incluye las plantillas de fallback |
| CLI: `qyro_cli/adapters/persistence/storage.py` | Settings del tooling, merge profundo y perfiles |
| CLI: `qyro_cli/adapters/freeze` | Hooks, PyInstaller, Cython, cifrado y optimización |
| CLI: `qyro_cli/adapters/package` | Layout release, formatos y firma/notarización |
| Pydux: `pydux/core` | Store, Action, selectores y tipos |
| Pydux: `pydux/toolkit` | Slices, configure_store y thunks |
| Pydux: `pydux/adapters` | Bindings, bridges y hooks Qyro |
| Pydux: `pydux/devtools` | Historial e inspector HTTP con assets |
| Pydux: `docs`, `examples`, `tests` | Uso público previsto y evidencia de comportamiento |

El [informe](/es/audit-report) registra contradicciones y validaciones de estos proyectos sin modificarlos.
